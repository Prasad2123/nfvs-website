# NF Venture Studio Website (NFVS)

> High-performance venture studio platform and institutional incubation portal connecting students, startups, MSMEs, and academia.

## 🚀 Overview

NF Venture Studio (NCF) transforms early-stage ideas and research into scalable enterprise ventures across four specialized deep-tech domains:
- **Artificial Intelligence & Machine Learning**
- **Internet of Things & Connected Systems**
- **Robotics & Mechatronics Prototyping**
- **Electronics & Embedded Hardware Systems**

## 🌟 Key Features

- **Full-Web Responsive Portal**: Built with React 18, TypeScript, Tailwind CSS, Lucide icons, and Framer Motion.
- **Dynamic Dual-Theme System**: Seamlessly switch between Executive Dark Mode (sapphire navy & gold glow) and Crisp Light Mode across all components.
- **3 Specialized Incubation Tracks**:
  - Track A: Student Innovators & Ideation
  - Track B: Early-Stage Hardware/Deep-Tech Startups
  - Track C: MSME & Institutional Enterprise Projects
- **Interactive Application & Lab Exploration Modals**: Direct intake form and detailed lab infrastructure specs.
- **Institutional Accreditation Matrix**: Mapping outcomes directly to NAAC, NBA, and NIRF criteria.
- **Contact & Helpline**: Direct contact integration for Ashok Patil (Nigdi, Pune) at `8379879846` / `9209112577`.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Desktop Application**: Electron (with secure IPC, native SQLite database)
- **Styling**: Modern glassmorphism, responsive grids, custom CSS variables for light/dark modes

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

`ash
# Install dependencies
npm install

# Start Vite web dev server
npm run dev
# or host on local network
npm run dev:host
`

### Building for Production

`ash
# Web production build
npm run build:web

# Desktop production build
npm run build
`
